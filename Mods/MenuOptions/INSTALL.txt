MENU OPTIONS 1.0.1
Extract this ZIP directly into Shooter/Binaries/Win64 with the game closed.
Separate package; Mod Menu and UE4SS are not included.
There is no named-mod or version dependency in the manifest.

Requires a compatible managed-package loader supplying the context APIs used
by Package/main.lua (query, readConfig, writeConfig, registerSettings,
registerMainMenuStyle, requestMenuBack, invalidate, log) and the existing
Goobies/UE4SS widget and input APIs. Locally tested using Mod Menu 1.0.0;
other loaders have not been tested. This package is not an auto-start UE4SS mod.

Installation: close the game, back up an existing MenuOptions folder and its
Win64/Configs/MenuOptions.ini, then extract Mods/MenuOptions into
<game>/Shooter/Binaries/Win64/Mods/. Preserve existing live Configs.
Do not add MenuOptions to UE4SS mods.txt; your compatible loader starts
Package/main.lua. With Mod Menu, enable Menu Options and click Refresh.

Controls: Escape closes Mod Menu; Custom buttons grows hovered main-menu text;
optional yellow hover outline; eight inline text colors; font size 30-60;
opacity 10-100%. Defaults: white, size 30, opacity 50%, growth on, outline off.
Sliders drag smoothly and snap on release; marked defaults and preview tooltips.
Saved settings are created locally; no author's personal settings are shipped.

Removal: close the game and remove only Mods/MenuOptions. Preserve its config
if you want to reinstall. Loader protections and installation are separate.
Local UI checks passed; font-size/outline combination and other-PC compatibility
are not fully verified. An intermittent Escape crash was reported in the tested
loader environment; its cause remains unresolved.
